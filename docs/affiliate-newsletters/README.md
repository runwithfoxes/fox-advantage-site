# Affiliate newsletter drafts

Generated drafts land here as `<product>-<YYYY-MM-DD>.md`, one per product per
Monday run. Each is a **draft for the head of growth to check and send**, not an
auto-send.

Produced by `scripts/affiliate-newsletter/` — see that folder's README for how
the workflow reads the week's commits, selects what affiliates care about, and
writes the copy.
