01The four hard rules
If we have the client, we show it as theirsA banner ad IS the brand. Real client work is shown named and owned. No re-skins, no hiding.
Never inventNo work for a client that doesn't exist. No client example for a capability? We show our own work.
Confidential insides stay privateThe brand is fine. Results, pricing, strategy data and letter recipients get masked.
Present tense"We're building", "we're running". A working studio, not an archive.

05Things to think about while you look
Which direction? A (impact), B (breadth), C (studio tightness). C matches the homepage language most closely; A demos best on a phone. A hybrid is possible: C rows, but the open row gets A's full-width capture.
How current is "current"? "On the bench this week" is a stronger frame than five permanent categories, but it means the page should change a little every few weeks or it reads stale. Categories age better.
Intro line. One sentence at the top sets the whole frame. Working draft: "Work in progress. A few things we're building at the moment."
Open-live exceptions. Metrics pyramid is the agreed one. Anything else earn a live link, or is one enough?
How loud are the names? A small client tag like the ones above, or the client in the headline ("A banner machine for Sabre")? Tag is calmer; headline sells harder.
