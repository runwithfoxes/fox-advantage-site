# Category research: find the sea of sameness

Step 1 of the website path. Do this before any design work.

## What you do by hand

1. List ten competitors. Include the big ones and two you admire.
2. Open each homepage in a browser at full width and take a whole-page screenshot. On a Mac, Claude Code can do this for you if you give it the addresses, or use the browser's own screenshot tool. Save them as `research/screenshots/01-name.png` and so on.
3. Copy the headline and the first paragraph of each homepage into `research/headlines.md`, one site per heading.

## What you paste into Claude Code

---

Read every screenshot in `research/screenshots/` and every entry in `research/headlines.md`. I am a marketer about to rebuild our website and I want to know what every site in this category already does, so that ours does not do it.

Give me four lists.

1. The words. Phrases that appear on three or more sites. Quote them.
2. The pictures. The kinds of image that appear on three or more sites (the smiling family, the handshake, the stock photo of a laptop, the icon row).
3. The shapes. The page order that most of them share: hero, three boxes, logos, testimonial, footer. Say how many of the ten follow it.
4. The gap. What nobody says, and what nobody shows. Be specific, and say which evidence you are reading it from.

Then write one paragraph, plainly, on what a site in this category would have to do to be the one people remember. Do not design anything yet.

Save all of it as `research/sea-of-sameness.md`.

## In the course

Kite's market is invented, so its research is already done for you in the `research/` folder: the forum threads, the reviews, Ardline's pages and the search questions. Run the same instruction over those files instead of screenshots. ## The rule

Everything in the output must point at a site or a line you can open. If Claude writes "most insurers say" without a quote, ask it which ones.
