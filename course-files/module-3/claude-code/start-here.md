# Start here

You have opened the Kite folder in Claude Code. This page is the first ten minutes.

## Before you type anything

In the Code tab, check three things at the bottom of the screen.

1. Environment says Local. That means Claude is working with the files on your own computer.
2. Project folder is this folder, Kite.
3. Permission mode is Manual. Claude will ask you before it changes a file or runs a command. Leave it there until you are comfortable.

## The first three things to say

Type each one, press Enter, and read what comes back before you type the next.

1. "Read every file in this folder and tell me in plain words what Kite is and what I have to work with."

   You are checking that Claude can see the folder. It should name the customer file, the rules files and the research files, and it should say Kite is invented.

2. "Make a file called notes.md in this folder with three lines: the three things you would check first in customers.csv before trusting any number in it."

   This is the first time Claude writes a file on your computer. In Manual mode it will show you the file and wait for you to accept it. Open notes.md afterwards and see that it is really there.

3. "How many customers are in customers.csv, and how many of them have a yes in the works_from_home column? Count it in code and show me the code."

   This is the first time Claude runs code for you. It should write a few lines of Python, run them, and give you two numbers. You do not need to read the code. You need to know it ran, and that the answer came from the file and not from a guess.

## What just happened

In module 2 you talked to Claude in a chat window and dropped files into a project. Here Claude is sitting at your computer. It can read a whole folder, write files you can open, and run code to count things. Everything else in this module uses those three moves.

## If something goes wrong

If the Code tab asks you to upgrade, Claude Code needs a paid plan (Pro, Max, Team or Enterprise). If Claude says it cannot see the files, check that the project folder at the bottom of the screen is the Kite folder and not the folder above it. If a step asks for permission you did not expect, say no and ask Claude what it was trying to do. Nothing in this folder matters, so you cannot break anything that cannot be downloaded again.
