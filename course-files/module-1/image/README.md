slim long-muzzled fox, two were closer after the prompt was corrected but still had orange paws
and a white tail tip. Paul: "none of these are good, you know that? is this /dray?" The fox
rules already said every Seedream run carries the fox reference. A fox image never goes on a
page unless it was made with the reference, whatever the lesson is about.

Six images was Paul's number. Five were made.
