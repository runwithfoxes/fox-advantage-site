01Try it first

Describe this so a machine could rebuild it

Here is a photograph. Write the description you would hand a machine so it could recreate this scooter somewhere else. Do it before you read on. It takes thirty seconds and it is the whole lesson.

02Compare

Yours, and one a machine wrote

No marking and no score. The only thing worth noticing is the gap, and which kinds of thing you left out. Almost nobody mentions the light, the lens, or the material of a surface, and those are what decide whether an image looks real.

What you did not have to do. You did not write that. You asked for it, from a picture. Which is the point: the description does the work, and you are allowed to have a machine write the description.

03Amend it in plain words

Ask for a change. Do not rewrite it yourself

You do not edit that description by hand. You say what you want different, in ordinary language, and ask for the prompt back with the change made. Pick one.

What came back, with the change folded in

Only the highlighted parts changed. You did not write any of it.

04The result

Same object, somewhere else

One photograph you already had, one description you did not write, one change you asked for in a sentence.

What the learner just did

  1. Tried to describe a picture and found out how much they leave out.
  2. Saw what a full description actually looks like, without writing one.
  3. Changed the situation by asking, in one sentence, in plain English.
  4. Got a new image of their own thing, somewhere else.
