What I'd recommend

What we would build for Nova HCM

This comes from our conversation. We would deliver an agent-led marketing system. A set of agents that do the marketing work, all of them running on one agreed strategy, so that everything they produce is on brand and on message without anyone having to check it. The first deliverable inside the system is the brand strategy, decoded into code, which becomes the DNA everything else runs on. Then the parts of the system that run on it: outbound agents to bring pipeline in, a new website, and a ghostwriter and social agent to build your authority in public. The last deliverable is Vanessa trained to run all of it.

Deliverable one · the foundation of the system

Brand strategy, decoded into code

The first thing we would deliver is the brand strategy. That is the positioning, the key target audiences, the key pain points, the key messages, the tone of voice and the brand identity. We work all of it out together and write it down properly in one place.

It is then decoded into code. Not a document that gets read once and filed, but a file that the website is built from and that every agent writes against. That file becomes the DNA of all Nova's marketing communications.

This is where most of the work goes, and everything else in the system depends on it. Once it is locked in, a LinkedIn post, a cold email and a page on the site all carry the same positioning and the same voice, because they are all produced from the same source. That is what lets the rest of the system run at speed without the quality dropping.

What the strategy covers
  • PositioningWhat Nova is, and who it is for.
  • Key target audiencesWho we are going after, and what each of them needs said to them.
  • Key pain pointsWhat actually brings someone to Nova.
  • Key messagesWhat we say back, agreed once and then used everywhere.
  • Tone of voiceWritten down precisely enough that the system can produce work in it.
  • Brand identityThe visual side, resolved and codified so everything built after it stays consistent.

Two issues we found while building it
  • Your DMARC record is set to monitor onlyYou told me the December campaign went to junk because DMARC was never set up. There is a record there now, which was the right move, but it is set to p=none. That means it reports mail that fails authentication without asking anyone to act on it. Your SPF is already strict, so the next step is to read a few weeks of reports, then move to quarantine, then reject. Worth doing before any new outreach goes out, and worth doing either way.
  • There is no sitemap, and robots.txt is emptynovahcm.ie/sitemap.xml returns a 404 and robots.txt is an empty file. Neither is breaking anything, but a sitemap tells search engines which pages exist and which matter. It is enabled once and then forgotten about. Worth closing, since your buyers start by searching.

Last · and the point of the whole thing

Handover to Vanessa

You said you needed someone to help build the system so you could enable someone like Vanessa. That is what this is for. She does not need to become a marketer. Running it should be a few tasks in her week.

In practice, the last part of the work is Vanessa doing each job herself: publishing an article, running an outbound batch from approval through to send, and changing something on the website. If she can do all three on her own, the handover is done. If not, we keep going until she can.

Buying the same capability the traditional way means four people: one on the website, one on outbound, one writing, and one on social. This puts it into a system your operations lead runs alongside her existing job. Nova owns it outright, which matters given you are building the business to sell.
