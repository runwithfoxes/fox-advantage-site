An agent here is a page of instructions in plain English

Claude Code reads the page and does what it says. This is Carlos, the first agent, the one that counts. One page, four questions.

What it produces
One file every Monday, one row per member, with the same fields every time: how often they usually come, their last three weeks, their notes.
Where it lands
A file in the folder, and one line in a log saying it ran. Enrique reads that file and nothing else.
How it knows it is done
Every member has a row. Run it twice on the same Monday and you get the same file.
What it does not do
It does not decide who is slipping. It does not write to anyone. It does not touch Attio.
An agent in this course is a page of instructions in plain English, and Claude Code follows it. This is Carlos, the one that counts. One page, four questions: what it produces, where it lands, how it knows it is done, what it does not do. Every agent you build is a page like this.

How you make one

Every one of these steps is spelled out, with what to press and what to type, in the build guide on the zorro page. Have it open while you work.

  1. Download the gym folder from runwithfoxes.com/zorro. Unzip it. Put it on your Desktop.
  2. Open a terminal. Type the two lines on the right. Claude Code opens inside the folder and can see the files.
  3. Make a new text file in the folder called carlos.md. In it, answer the four questions in plain English. That file is the agent.
  4. Tell Claude Code: read carlos.md and do it for member Z0811. Look at what comes out.
  5. Run it on ten members. Look again. Fix carlos.md where it went wrong.
  6. Run it on all 900. Then run it a second time on the same Monday. It must give the same answer. If it does not, the page is not finished.

How the agents talk to Attio

  1. One person on your team makes a free Attio workspace and invites the others.
  2. In Attio, make an API token. It is a long password that lets a program write to your workspace.
  3. Put the token in the gym folder, in a file called .env. Never in the page, never in a chat.
  4. Run the loader. It makes the member fields and puts all 900 members in as cards.
  5. From then on, Enrique writes the reason and the email onto a card and moves it to a column.

I will show this on my own workspace now. The columns are steady, slipping, emailed, ask Marta, came back, didn’t come back.

What starts them: a clock, not you

  1. Nothing starts an agent on its own. This week a timer on your laptop wakes a small runner every 30 minutes. The runner asks: is it Monday, is this Monday done? If yes and no, it starts Carlos, then Enrique, then Cato, then Rosa, each when the one before has left its file.
  2. The runner and the timer are in the folder already, in tools. On Tuesday, once Enrique works, you set the timer with one line. Steps 28 to 31 of the build guide.
  3. Every run writes one line per step to heartbeat.log. That file is the proof it ran. A timer that says it is loaded proves nothing.
  4. In a company the same four pages run on Anthropic’s Managed Agents, in the cloud, on their own timetable. No laptop has to be open. Same pages, a different clock.
