The build guide

How to build the three agents for Gimnasio Zorro, one step at a time. Each step is one thing to do. It says what to press, what to type, and what you should see when it worked. If what you see is different, stop there and ask Isa on the zorro page, with the step number.

A. Get set up. About twenty minutes, once. B. Make Carlos, the one who counts. Tuesday morning. C. Make Enrique, the one who writes and sends. Tuesday. D. Connect Attio, so the emails land on the cards. E. Make Cato, the one who checks. Thursday.

A. Get set up. About twenty minutes, once.

1

Download the gym folder

Go to runwithfoxes.com/zorro, type the password, scroll to "The gym files" and click Download beside gimnasio-zorro.zip. It lands in your Downloads folder.

runwithfoxes.com/zorro
gimnasio-zorro.zip
The whole folder: the three data files, the three pages, the three role pages, the runbook and the set-up sheet.
Download
You should seeA file called gimnasio-zorro.zip in Downloads.
2

Unzip it and put the folder on your Desktop

Open Downloads. Double-click gimnasio-zorro.zip. A folder called gimnasio-zorro appears beside it. Drag that folder onto your Desktop.

Desktop
gimnasio-zorro/
data/ members.csv checkins.csv email_log.csv
messaging/ gimnasio-zorro.md email-voice-and-rules.md messages-by-goal.md
pages/ carlos-role.md enrique-role.md cato-brief.md ...
tools/ attio.py
You should seeA folder called gimnasio-zorro on your Desktop with four folders inside it: data, messaging, pages, tools.

On a Mac double-clicking the zip unzips it. On Windows right-click the zip and choose Extract All, then Extract.

3

Open a terminal

A terminal is a window where you type commands instead of clicking. Claude Code runs inside it.

terminal
Last login: Mon Sep 14 18:02:11
$
You should seeA mostly empty window with a line ending in a dollar sign or a greater-than sign, and a blinking cursor. That is where you type.

On a Mac press Cmd and Space together, type Terminal, press Enter. On Windows press the Windows key, type PowerShell, press Enter.

4

Go into the gym folder

Type the line below exactly, then press Enter. Nothing dramatic happens. The prompt now shows the folder name, which means you are inside it.

terminal
$ cd Desktop/gimnasio-zorro
gimnasio-zorro $
You should seeThe prompt changes to include gimnasio-zorro.

On a Mac cd Desktop/gimnasio-zorro On Windows cd Desktop\gimnasio-zorro

5

Check you are in the right place

Type ls and press Enter. It lists what is in the folder.

terminal
gimnasio-zorro $ ls
data messaging pages tools
You should seeFour names: data, messaging, pages, tools. If you see something else, you are in the wrong folder. Type cd and press Enter to go home, then do the step above again.

On a Mac ls On Windows dir

6

Start Claude Code

Type claude and press Enter. The first time, it opens your browser to log in. Log in with your Claude account and come back to the terminal. It may ask "Do you trust the files in this folder?" Press Enter for yes.

terminal
gimnasio-zorro $ claude
Welcome to Claude Code
Do you trust the files in this folder? Yes
>
You should seeA box with a > prompt. Everything from here on, you type into that box and press Enter.
7

Know the one thing it will ask you

Claude Code asks before it reads or writes a file, and before it runs a command. When it asks, read what it wants to do, then press Enter to say yes. You will do this a lot. It is not an error.

claude code
Claude wants to create carlos.md
Yes Yes, and don't ask again for this folder No
press Enter
You should seeThe thing it asked for gets done, and it tells you.

B. Make Carlos, the one who counts. Tuesday morning.

8

Make the page

Carlos is a text file called carlos.md with four headings on it. Ask Claude Code to make the empty file. Type the line below into the > box and press Enter.

claude code
> Make a file called carlos.md in this folder with these four headings and nothing under them: What it produces. Where it lands. How it knows it is done. What it does not do.
Created carlos.md with the four headings.
You should seeA new file called carlos.md in the gym folder. Open the folder on your Desktop and you will see it.
9

Answer the first question: what it produces

Now you write the job. Tell Claude Code what to put under the first heading. This is what a good answer looks like. Put it in your own words, but keep every number in it.

carlos.md
## What it produces
One row per member, with these fields: member_id, first_name, last_name, goal, notes, visits_per_week_last12 (twelve whole numbers, oldest week first), usual_per_week (the average of the first nine of those twelve weeks, to two decimal places), visits_last3 (the last three weeks added up).
A week runs Monday to Sunday. The twelve weeks are the twelve full weeks before the Monday being run. Only swipes dated before that Monday count.
You should seeType: "Put this under What it produces:" and then your answer, and press Enter. Claude Code writes it into the file and says so.
10

Answer the other three

Do the same for the other three headings. These are good answers. Notice each one can be checked, and the last one is a list of things it must not do.

carlos.md
## Where it lands
A file called carlos-out.json in this folder, one row per member. And one line printed to say how many rows were written.
## How it knows it is done
Every member in data/members.csv has a row. Running it twice on the same Monday gives the same file.
## What it does not do
It does not decide who is slipping. It does not write to any member. It does not touch Attio.
You should seecarlos.md with all four questions answered. Ask Claude Code "show me carlos.md" to read it back.
11

Run it for one member

This is what "run it" means: you tell Claude Code to read the page and do what it says, for one member. Type the line below and press Enter. It will read the files, count the swipes, and may write a small program to do the counting. That is fine. That program is Carlos. It takes about a minute.

claude code
> Read carlos.md and do what it says, but for member Z0811 only, as of Monday 31 August 2026. Use the files in data. Show me the row you produce.
Here is the row for Sergio Rubio (Z0811), as of Monday 31 August 2026:
{"member_id": "Z0811", "first_name": "Sergio", "last_name": "Rubio", "goal": "build muscle", "notes": "", "visits_per_week_last12": [2, 4, 3, 3, 3, 3, 4, 3, 3, 0, 0, 0], "usual_per_week": 3.11, "visits_last3": 0}
He came in about three times a week through the first nine weeks: 28 visits, so 28 divided by 9 is 3.11. His last swipe before the cut-off was Saturday 8 August, so the last three weeks add up to 0.
You should seeOne row for Sergio Rubio. The twelve numbers should be 2 4 3 3 3 3 4 3 3 0 0 0, the usual should be 3.11, and the last three weeks should be 0. If your numbers are different, your page said something different. Read it again.
12

Check the row against the sheet

Do not take its word for it. Open the check-ins sheet on the zorro page, use the filter to show only Z0811, and count his swipes in the last three weeks before 31 August. There should be none. Then count one of the earlier weeks and compare it to the row.

Gimnasio Zorro, the check-ins
member id swiped in at
Z0811 2026-08-03 18:41
Z0811 2026-08-05 18:22
Z0811 2026-08-08 10:15
(nothing between 10 August and 30 August)
You should seeThe numbers in the row match what you counted. If they do not, tell Claude Code exactly which number is wrong and what you counted. It will find why.
13

Run it for your team's ten

Download your team's ten-member pack from the zorro page and drag it into the gym folder. Then type the line below. Change team01 to your team number.

claude code
> Read carlos.md and do what it says for every member listed in team01-build10.csv, as of Monday 31 August 2026. Show me the ten rows.
Ten rows follow.
{"member_id": "Z0652", "first_name": "Alba", ... "visits_last3": 1}
{"member_id": "Z0867", ...}
...
You should seeTen rows. Look at each one against the visits in the pack file. Where a row is wrong, fix the wording in carlos.md, then run the ten again.
14

Run it for all 900

Now the real thing. Type the line below and press Enter. It takes a few minutes. It will ask before it writes the file. Press Enter for yes.

claude code
> Read carlos.md and do what it says for every member in data/members.csv, as of Monday 31 August 2026. Write the file carlos.md says to write.
Wrote carlos-out.json with 900 rows.
You should seeA file called carlos-out.json in the gym folder, and a line saying 900 rows. Ask "how many rows are in carlos-out.json?" and it must say 900.
15

Run it a second time

This is the test that matters. Type the same line again, exactly. It should give exactly the same file. Then ask it to compare.

claude code
> Read carlos.md and do what it says for every member in data/members.csv, as of Monday 31 August 2026. Write the file carlos.md says to write.
Wrote carlos-out.json with 900 rows.
> Compare the file you just wrote with the one you wrote before. Are they identical, row for row?
Yes. All 900 rows are identical.
You should seeYes, identical. If it says no, the page is not finished: something in carlos.md leaves room for a different answer. Ask Claude Code which rows differ and why, and tighten the page.
16

Stuck?

Ask Isa on the zorro page first. Tell her the step number, what you typed, and what you saw. She has read every page. If she cannot help, ask Julie or Paul in the room.

C. Make Enrique, the one who writes and sends. Tuesday.

17

Make the page

Same as Carlos. Ask Claude Code to make enrique.md with the four headings. Then answer them. Enrique reads Carlos's file and the three pages in messaging. He never opens the check-ins.

enrique.md
## What it produces
One decision per row of carlos-out.json: member_id, decision (draft, skip or ask), reason (one line quoting the numbers or the note), email (the email, or nothing).
## Where it lands
A file called enrique-out.json in this folder. For every draft, the email goes in data/email_log.csv with the date. Later: the reason and the email on the member's card in Attio.
## What it does not do
It never opens data/checkins.csv. It does no arithmetic. It never writes to a member whose note says away or injured. It never mentions fees, renewal, or the member's private life.
You should seeenrique.md with the four answers. The rules for the email are in messaging/email-voice-and-rules.md; tell Claude Code to read that page and messages-by-goal.md when it decides.
18

Run it for one member

Type the line below. It reads the row Carlos made, the three pages, and decides.

claude code
> Read enrique.md, the three pages in messaging, and carlos-out.json. Do what enrique.md says for member Z0811 only. Show me the decision, the reason and the email.
Decision: draft. Reason: visits_last3 0 against usual_per_week 3.11; no note.
Hi Sergio,
Marta here, and I noticed you have not been in for a few weeks. You put real work into what you built here, and it is worth keeping. The floor has been quiet in the evenings and your bench is free. Could you come in for one session this week?
Marta
You should seeA decision, a reason with the numbers in it, and an email under eighty words with one ask and nothing about fees or his private life. Read it as Marta. Would she send it?
19

Then ten, then all 900, then a second time

Exactly as for Carlos: your team's ten, then every row in carlos-out.json, then the same line again and "are they identical?". The decisions must not change between runs.

You should seeenrique-out.json with 900 rows, the same twice.

D. Connect Attio, so the emails land on the cards.

20

Make the workspace

One person on the team goes to attio.com and makes a free workspace. Name it Zorro and your team number. Invite the others by email. Do not pay for anything.

You should seeEveryone on the team can open the workspace and sees an empty People list.
21

Make a token

In Attio, open Settings, then Developers, then make a new access token. Give it read and write access to People and to object configuration. Copy the token. It is one long line of letters and numbers. You only see it once.

attio, settings, developers
Access tokens
New access token
Name: zorro Scopes: People read and write, Object configuration read and write
Copy
You should seeA long token on your clipboard.
22

Put the token in a file called .env

Back in Claude Code, type the line below, pasting your token in place of the dots. Claude Code makes the file. Never paste the token anywhere else, and never put it in a page.

claude code
> Make a file called .env in this folder with exactly one line: ATTIO_TOKEN=..........
Created .env. I will not print the token back.
You should seeA file called .env in the gym folder. You will not see it in the Desktop folder, because files that start with a dot are hidden. That is fine.
23

Load the members

The loader is in tools. Ask Claude Code to run it, three times, in this order. The first makes the fields on People, the second puts the 900 members in, the third counts them.

claude code
> Run python3 tools/attio.py setup, then python3 tools/attio.py import, then python3 tools/attio.py count. Show me what each prints.
made member_id ... made status ... option steady ...
imported 900 members
900 people in the workspace
You should seeOpen Attio. People now has 900 cards, each with a goal, a plan and a status of steady.
24

Send Enrique's emails to the cards

Now Enrique's decisions go onto the cards. Ask Claude Code to write each draft as emailed, with the reason and the email, and each ask as ask marta.

claude code
> For every row in enrique-out.json, put the reason and the email on that member's card in Attio and set the status: emailed for a draft, ask marta for an ask. Use tools/attio.py as the example of how to write to a card.
Written 65 cards as emailed and 10 as ask marta.
You should seeIn Attio, the emailed members carry the reason and the email on their card. Click Sergio Rubio.

E. Make Cato, the one who checks. Thursday.

25

Make the page and run him

cato.md is the same four questions. His job is to assume Carlos and Enrique are wrong and prove it: recount the numbers from the check-ins himself, decide for each member from enrique.md's rules himself, and write disagree wherever his answer differs. His page is in pages/cato-brief.md.

claude code
> Read cato.md and pages/cato-brief.md. Do what they say for every member, as of Monday 31 August 2026, without reading carlos-out.json or enrique-out.json until you have your own answer. Then compare, and show me every row where you disagree and why.
900 rows checked. 3 disagreements:
Z0693 Lucía Rodríguez: Enrique said draft. Her note says she comes every other week. Skip.
You should seeA list of rows where Cato disagrees, each with the reason quoted from the data. Every one of those is a line to fix in carlos.md or enrique.md. Fix it, run again, and the list should get shorter.
